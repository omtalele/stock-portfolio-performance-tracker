
# Stock Portfolio Performance Tracker

## Project Overview
A Python console application to track stock portfolio performance.

## Features
- Enter stock ticker, buy price, and quantity
- Calculate investment and current value
- Calculate gain/loss and percentage
- Save transaction records to a CSV file

## Technologies Used
- Python 3
- CSV module
- OS module
- Datetime module

## How to Run
Run the following command:

python stock_portfolio.py
